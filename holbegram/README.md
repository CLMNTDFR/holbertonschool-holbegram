# Holbegram

Instagram-like mobile app built with Flutter. Firebase handles auth and the database, Cloudinary stores the pictures.

## Setup

```bash
cd holbegram
flutter pub get
flutter run
```

Firebase is linked for Android and Chrome (`lib/firebase_options.dart`).

```bash
cd holbegram
flutter pub get
flutter run -d chrome
```
